MarkdownDO

An opinionated TODO.md manager for your terminal

Download

I built MarkdownDO to help me complete my projects, so it's tailored to my workflow. It's optimised to work with one TODO.md file per project or folder. You can easily add new task, organise them by categories, mark them as completed, and there's also some more fancy commands to clean up your lists. Still, MarkdownDO is highly opinionated and wants to stay minimalistic in it's approach. For this reason there are not tags, no due dates, etc.

What makes it great

Fast CLI

Add, toggle, and manage tasks without leaving your terminal

Interactive TUI

Full keyboard navigation with hotkeys

Plain markdown

Tasks are standard - [ ] checkboxes, readable anywhere

Sections

Organise your tasks with ## Headers

Inbox workflow

New tasks go to the top unless you specify a section

Lint & fix

Auto-fix common formatting issues
