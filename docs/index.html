MarkdownDO

A fast, minimal, opinionated CLI/TUI tool for managing TODO.md files using standard markdown syntax.

Read the docs GitHub

What you get

  • Plain markdown

    Tasks are standard - [ ] checkboxes, readable anywhere

  • Fast CLI

    Add, toggle, and manage tasks without leaving your terminal

  • Interactive TUI

    Full keyboard navigation with hotkeys

  • Sections & inbox

    New tasks land in the inbox unless you file them into a section

  • Auto-sorting

    Tasks reorder by status on save, so active work stays on top

  • Lint & fix

    Auto-fix common formatting issues in your TODO.md
